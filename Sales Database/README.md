# 🛒 Sales Data Analysis Using SQL  
### Data Analyst Portfolio Project | SQL-Based Business Insights

## 📌 Project Overview 

This project demonstrates end-to-end data analysis using SQL on a structured e-commerce Sales Database.

The objective was to simulate real-world business scenarios and extract actionable insights related to:

- Customer behavior analysis  
- Revenue performance tracking  
- Product performance evaluation  
- Payment trend analysis  
- Operational reporting  

Over **60+ SQL queries** were written to solve business problems across multiple complexity levels — from basic filtering to advanced analytical queries.

## 📊 Business Analysis Performed  

### 🔹 Customer Analytics  

- Identified active vs inactive customers  
- Calculated total customer lifetime revenue  
- Measured order frequency per customer  
- Detected high-value customers  
- Identified customers for re-engagement campaigns  

### 🔹 Revenue & Sales Insights  

- Computed total revenue and average order value  
- Analyzed daily order trends  
- Measured revenue contribution per customer  
- Identified unusually high transactions  
- Segmented revenue by payment method  

### 🔹 Product & Category Performance  

- Evaluated total products sold per category  
- Measured average pricing by category  
- Identified premium-priced products  
- Detected unsold products  
- Monitored inventory gaps (out-of-stock items)  

### 🔹 Operational & Transaction Reporting  

- Built customer-order-payment integrated reports  
- Generated line-level revenue calculations  
- Identified data inconsistencies (orphan records)  
- Created date-wise reporting views
